# CookieBot — Windows 실험용 자동 플레이 기반 구현

**완성된 카카오 쿠키런 무인 플레이 AI가 아닙니다.** 실행 가능한 캡처·규칙 기반 인식·추적·궤적 예측·입력·GUI·기록·녹화 재생 도구입니다. 실제 게임 이미지, Windows, 에뮬레이터에 접근하지 못했으므로 게임에서의 인식/회피/자동 재시작 성공은 미검증입니다. 기본값은 키를 보내지 않는 관찰 모드입니다.

## Windows 설치 및 실행

1. python.org에서 Python **3.11 64비트**를 설치합니다. Python Launcher와 Tcl/Tk 옵션을 포함하세요.
2. ZIP을 일반 폴더에 압축 해제하고 `INSTALL.bat`를 실행합니다. 인터넷 연결이 필요합니다.
3. `CHECK.bat`로 의존성과 OCR 초기화를 검사합니다.
4. 게임/에뮬레이터를 창 모드로 띄우고 `RUN.bat`를 실행합니다.
5. 창 제목으로 검색하고 목록에서 게임 창을 선택합니다. 자동 플레이 시작 후 게임 창에 포커스를 줍니다.
6. 디버깅 창에서 인식을 먼저 확인합니다. 실제 입력은 정지한 뒤 관찰 모드를 끄고 다시 시작하면 활성화됩니다.
7. **F8** 또는 `STOP.bat`로 정지합니다. GUI 종료도 키를 해제합니다. 디버그 창이 포커스를 가지면 게임 입력이 일시 해제됩니다.

모든 BAT는 완료/실패 후 pause로 창을 유지합니다. 설치 오류는 `logs/install.log`, 런타임은 `logs/run.log`, 예외는 `crash_logs/`에 저장합니다. Python 3.11 설치 자체는 BAT가 수행하지 않습니다.

## 설정 및 작동 범위

`config.json`에서 CapsLock 점프, Enter 슬라이드, FPS, 창 제목, 캐릭터 예상 가로 위치/바닥 높이를 설정할 수 있습니다. 분석은 960×540 좌표계로 변환됩니다. 창 이동/크기는 매 프레임 Windows 클라이언트 영역을 조회해 반영하지만 에뮬레이터 내부 레터박스/도구 모음 자동 분리는 구현되지 않았습니다. 화면 구도에 따라 player_x/ground_y 보정이 필요합니다. 개별 장애물 이미지 등록은 요구하지 않습니다.

- 인식: 윤곽, 크기, 움직임, 반복 형태로 장애물/젤리 가설을 생성합니다. 바닥 경계의 불연속을 구멍으로 추정합니다. 불확실한 객체는 unknown입니다. **배경 장식 및 실제 젤리와의 오분류를 해결했다고 주장하지 않습니다.**
- 추적: 위치 예측 기반 연결 및 수평 속도 평활화.
- 제어: 1.2초 궤적 시뮬레이션으로 달리기/점프/이단점프/슬라이드를 비교합니다. 점프 유지 시간에 따른 실제 궤적 차이는 아직 보정되지 않았습니다. 연속 프레임에서 재계획합니다.
- 입력: 키의 눌림/해제를 예약하고 10ms 감시 스레드가 F8, STOP, 포커스, 처리 정체를 확인합니다. 입력 지연 로그는 API 호출 시간이며 게임이 실제 입력을 처리한 시간은 아닙니다.
- 메뉴: OCR 결과에서 `free start`, `free retry`, `free restart`, `무료 시작`, `무료 재시작`과 정확히 일치하는 고신뢰 버튼을 3회 확인해야 클릭합니다. 결제 관련 문구는 중단합니다. **일반 시작/다시하기 버튼과 한국어 화면 전체를 안정적으로 처리하지 못합니다. 무료 표시가 없으면 자동 진행하지 않습니다. OCR 누락에 대한 무결성 보장은 없습니다.**
- 기록: SQLite 판단/객체/입력 로그와 1초 간격 JPEG. 점수·충돌 결과는 알 수 없으므로 NULL로 저장합니다. runs의 seconds는 작업 실행 시간이며 게임 생존 시간이 아닙니다. 장시간 기록은 디스크 공간을 소비합니다.
- 정책 검증 함수: 검증된 동일 시나리오 결과 30쌍 이상에서 충돌 증가가 없고 생존 합계가 5% 넘게 개선된 경우만 승인합니다. **자동 데이터 라벨링, 학습 실행, 정책 배포/자동 롤백은 구현되지 않았습니다.** 이 함수만으로 학습 시스템이 완성되는 것은 아닙니다.

## 아직 필요한 실제 개발/검증

게임 화면에 맞춘 객체·캐릭터 상태 인식(피격/사망/변신/이단점프 등), 실제 물리 계측, 메뉴/결제 화면 검증, 점수와 플레이별 종료 판정, 실패 원인 분류, 보상 측정, 정책 후보 생성/검증/복구, GUI 플레이 통계는 미완료입니다. 게임 창 자동 검색은 제목 필터이며 게임 콘텐츠 식별기가 아닙니다. GUI 체크박스 변경은 다음 시작부터 적용됩니다. UI 초기화는 체크박스 초기화이며 config.json 전체를 덮어쓰지 않습니다.

이 제한을 해결하기 위해 다음 단계에는 실제 게임 녹화(메뉴·플레이·실패·결과 포함)와 Windows 실행 검증이 필요합니다. 녹화 수집을 위해 수동 점프 타이밍/장애물 라벨링을 할 필요는 없습니다. 자동 관찰 모드도 기록을 남깁니다.

## 개발 및 녹화 분석

```
python -m pip install -r requirements.txt
python -m pip install pytest==8.3.5
python -m pytest -q
python -m cookiebot.replay recording.mp4 --output replay.jsonl
```

리플레이는 입력을 보내지 않고 프레임별 객체와 행동 가설을 JSONL에 기록합니다. 예측 결과만으로 실제 플레이 성공이나 정책 개선을 판단하지 마세요.

`docs/TEST_RESULTS.md`에 검증 범위, `docs/OPEN_SOURCE.md`에 라이브러리 검토를 기록합니다. 테스트 이미지는 코드로 생성한 기하 도형이며 실제 게임 학습 데이터가 아닙니다.
